# Arquivo Documental

Esta pasta preserva documentos históricos. Seu conteúdo não define o estado
atual do projeto.

Para entender o presente, comece em [docs/project](../project/README.md).

## Organização

- [2026-08-10-limpeza-documental](2026-08-10-limpeza-documental/): fotografia
  integral anterior à limpeza, planos concluídos, fases, revisões e referências
  superadas.

## Regra de uso

- Consulte o arquivo para rastrear decisões, evidências e contexto.
- Confirme qualquer afirmação no código e em docs/project antes de usá-la.
- Não edite um documento histórico para fazê-lo parecer atual.
- Se uma conclusão histórica voltar a ser válida, registre uma decisão nova no
  núcleo ativo.
