# Propostas Iniciais

Aqui devem ficar registradas propostas comerciais, cronogramas datados, estimativas e textos de negociação que fizeram parte da origem do projeto.

## Regra

- podem ser usados para entender intenção e contexto;
- não podem ser usados como prova de estado atual;
- qualquer trecho ainda válido deve ser promovido para `docs/project/` ou `docs/product/`.
