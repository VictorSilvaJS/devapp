# Reuniões Iniciais

As reuniões iniciais são fonte principal para entender:

- visão do problema;
- dores do negócio;
- mudança de entendimento;
- decisões de acesso e domínio;
- vocabulário do projeto.

## Regra de uso

- tratar como evidência histórica;
- extrair decisões para documentos ativos;
- não assumir que tudo o que foi falado continua valendo.
