# Histórico de Origem do Projeto

## Finalidade

Registrar a origem do projeto e preservar o contexto de descoberta, reuniões, propostas e protótipos iniciais.

## Observação importante

Este material é valioso para entender a evolução do projeto, mas não deve ser tratado como estado atual automaticamente.

## Tipos de material que pertencem aqui

- transcrições de reunião;
- propostas iniciais;
- cronogramas antigos;
- versões antigas de visão e escopo;
- apresentações de protótipo;
- rascunhos técnicos iniciais;
- snapshots de mockups.
