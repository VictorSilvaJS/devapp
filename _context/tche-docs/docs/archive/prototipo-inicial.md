# Protótipo Inicial

Este espaço preserva referências de mockup, protótipo inicial, estrutura visual preliminar e trechos de implementação apresentados como prova de conceito.

## Regra

- protótipo não equivale a produto final;
- mockup não equivale a regra de negócio definitiva;
- código inicial embutido em material histórico não equivale ao estado atual do repositório.
