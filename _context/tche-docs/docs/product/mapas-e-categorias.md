# Mapas e Categorias

## Papel dos mapas no produto

Mapas são parte central do valor do sistema. A plataforma deve organizar e disponibilizar mapas no contexto certo, de forma clara para equipe e cliente.

## Organização recomendada

Os mapas devem ficar associados a:
- produtor;
- fazenda;
- categoria;
- período/ano/safra quando aplicável.

## Categorias-base

As categorias abaixo são um ponto de partida forte para o produto:

- fertilidade;
- correção;
- índice de vegetação;
- colheita;
- aplicação;
- panorama;
- limite/shape, quando o fluxo exigir separação clara.

## Regras

### 1. Categoria explícita
Todo mapa deve ter categoria clara.

### 2. Contexto temporal
Quando relevante, o usuário deve conseguir diferenciar mapas por ano, safra ou período.

### 3. Download controlado
Nem todo mapa precisa estar liberado para todo perfil.

### 4. Panorama e limite
Panorama visual e mapa de limite/demarcação podem exigir tratamento próprio na experiência, mesmo quando pertencem à mesma fazenda.

## Observação

A taxonomia final deve ser revisada sempre que a equipe consolidar o catálogo real de mapas usados no negócio.
