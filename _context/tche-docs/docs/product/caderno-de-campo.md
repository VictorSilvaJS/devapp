# Caderno de Campo

## Objetivo

Registrar atividades de campo de forma útil, enxuta e alinhada à rotina da operação.

## Diretriz principal

O caderno de campo não deve nascer como um formulário gigantesco. Deve começar focado no que gera valor operacional real.

## Escopo inicial recomendado

- tipo de atividade;
- data;
- fazenda/talhão;
- responsável;
- observações;
- recomendações;
- anexos/fotos quando fizer sentido.

## Foco do domínio

Como o projeto tem forte relação com fertilidade, o caderno deve priorizar atividades que dialoguem com esse contexto, evitando virar um sistema agrícola genérico demais logo no começo.

## Visibilidade

A visibilidade do caderno de campo deve ser controlada por perfil e por regra de negócio.

## Ponto de atenção

Os campos obrigatórios e opcionais ainda precisam de refinamento. Portanto, este documento deve ser atualizado conforme a rotina real for melhor consolidada.
