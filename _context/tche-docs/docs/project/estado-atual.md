# Estado Atual do Projeto

## Objetivo atual

O projeto Tchê busca organizar e disponibilizar informações agrícolas da lavoura em uma plataforma digital centrada na propriedade/fazenda, com foco em mapas, arquivos técnicos, histórico de visitas e registros de campo.

## O que deve ser considerado verdade operacional agora

- O sistema deve atender três visões principais: administração geral, colaborador regional e cliente/produtor.
- O cliente/produtor acessa sua própria propriedade para consultar dados e baixar arquivos.
- O colaborador atua sobre uma região delimitada e não deve acessar dados fora do seu escopo.
- A administração geral possui visão ampla do sistema.
- O projeto deve considerar uso em campo, com necessidade de suporte offline ao menos para consulta.
- O núcleo do MVP está ligado a propriedades, fazendas, mapas, arquivos, visitas e caderno de campo.
