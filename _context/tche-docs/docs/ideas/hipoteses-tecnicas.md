# Hipóteses Técnicas

## Objetivo

Registrar possibilidades técnicas discutidas ao longo do histórico do projeto para que não se percam, sem transformá-las em compromisso atual.

## Hipóteses relevantes

- uso de stack voltada a web + mobile + backend estruturado;
- modelagem geoespacial especializada;
- pipeline para mapas e materiais de geoprocessamento;
- consulta a imagens/índices de satélite;
- estratégias de visualização e categorização avançada de mapas;
- infraestrutura híbrida com preocupação de posse e backup;
- componentes de notificação e sincronização mais sofisticados.

## Como usar este documento

Use como reservatório de ideias para avaliação futura. Não usar como fonte de implementação direta sem validação no contexto atual do projeto.
